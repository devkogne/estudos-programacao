# 💰 Controle Financeiro

Aplicação web simples para controle de entradas e despesas.

Este projeto foi desenvolvido como parte dos meus estudos de programação, utilizando HTML, CSS e JavaScript.

## 🚀 Funcionalidades

- Adicionar entradas
- Adicionar despesas
- Calcular o saldo automaticamente
- Listar movimentações
- Validar descrição e valor
- Interface responsiva

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

Durante o desenvolvimento deste projeto, pratiquei:
