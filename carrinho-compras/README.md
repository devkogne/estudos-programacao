# 🛒 Carrinho de Compras

Projeto desenvolvido durante meus estudos de programação na Alura.

## 📚 Sobre o projeto

Um carrinho de compras simples desenvolvido com HTML, CSS e JavaScript.

O projeto permite adicionar produtos ao carrinho, calcular o valor de cada item e atualizar o valor total da compra.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 💡 Conceitos praticados

- Manipulação do DOM
- Funções
- Variáveis
- Operações matemáticas
- Eventos
- `getElementById()`
- `innerHTML`
- `textContent`
- Manipulação de strings
- Arrays e métodos de string

## 🎯 Objetivo

Praticar os fundamentos de JavaScript e a interação entre JavaScript e uma página HTML.
